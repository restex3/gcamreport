## 🔍 各部门详细情况

### 1. 农业部门 (Agriculture & Livestock)

#### 数据可用性

| 数据类型 | 空间分辨率 | 状态 |
|---------|-----------|------|
| 作物生产 | 国家级 | ⚠️ 需要分配到省级 |
| 作物需求 | 省级 | ✅ 可直接使用 |
| 畜牧业生产 | 国家级 | ⚠️ 需要分配到省级 |
| 畜牧业需求 | 国家级 | ⚠️ 需要分配到省级 |
| 饲料需求 | 省级 | ✅ 可用于畜牧业分配 |

#### 分配策略

**作物生产分配**:
```
省级作物生产 = 国家级作物生产 × (省级作物需求 / 全国作物需求)
```

**畜牧业生产分配**:
```
省级畜牧业生产 = 国家级畜牧业生产 × (省级饲料需求 / 全国饲料需求)
```

#### 挑战

- 需要开发和验证分配算法
- 畜牧业分配基于饲料需求代理，需要验证准确性
- 需要建立畜产品-饲料类型映射关系

#### 工作量: 7-8周

1. **分阶段实施**: 先完成简单部门，积累经验

3. **文档完善**: 详细记录映射关系和假设
