# Development Scripts

This directory contains development and testing scripts that are not part of the main package.

## Files

- `GCAM-China_compare_official.R` - Compare results with official GCAM-China outputs
- `GCAM-China_fullcheck.R` - Full validation check for GCAM-China support
- `GCAM-China_mapping_fallbacks.R` - Test mapping fallback mechanisms
- `GCAM-China_test.r` - Basic GCAM-China functionality tests
- `check_regions_number.R` - Validate region counts
- `rebuild_mappings.R` - Rebuild mapping files from source
- `china_co2_market_mapping.csv` - CO2 market mapping data for China
- `test.dat` - Test data file

These scripts are for development purposes only and are excluded from the R package build.
